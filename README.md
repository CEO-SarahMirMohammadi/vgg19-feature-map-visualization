# VGG19 Feature Map Visualization

Visualization of convolutional feature maps generated by different hidden layers of the pretrained VGG19 convolutional neural network using Keras.

This project modifies a VGG19 image-processing example to visualize the feature maps produced by the **second, third, and fourth convolutional layers**. The experiment demonstrates how convolutional neural networks progressively extract visual features from an input image.

## Overview

Convolutional Neural Networks (CNNs) learn visual representations hierarchically.

Early convolutional layers generally detect simple patterns such as:

* Edges
* Lines
* Basic textures
* Changes in intensity

As the network becomes deeper, these simple features are combined into more complex visual patterns.

This project uses **VGG19**, pretrained on ImageNet, to visualize these learned representations.

## Objective

The objective of this exercise is to modify the original VGG19 feature-map visualization example by changing the selected hidden layer:

```text
n = 2
n = 3
n = 4
```

The generated feature maps are then visualized and compared.

## Model

The project uses the pretrained **VGG19** architecture from Keras.

VGG19 is a convolutional neural network containing multiple convolutional and fully connected layers. The pretrained model provides learned convolutional filters that can be used to extract visual features from new images.

## Input Image

The experiment uses:

```text
Elephant.jpg
```

The image is resized to:

```text
224 × 224 pixels
```

which is the standard input size expected by VGG19.

## Feature Map Visualization

The experiment examines three convolutional layers.

### Layer 2

The second convolutional layer generally produces feature maps representing relatively simple visual patterns such as:

* Edges
* Lines
* Basic intensity changes
* Simple textures

### Layer 3

The third convolutional layer combines simpler features into more structured patterns.

The feature maps may contain more complex texture and shape information than the previous layer.

### Layer 4

The fourth convolutional layer represents increasingly complex combinations of previously extracted features.

This demonstrates the hierarchical nature of CNN feature extraction.

## Results and Observations

The experiment demonstrates that CNN feature extraction is hierarchical.

At earlier convolutional layers, the feature maps tend to emphasize simple visual structures such as edges and basic textures.

At deeper layers, these simple features are combined into more complex representations.

Therefore, changing the selected layer changes the type of visual information represented by the feature maps.

The exact appearance of the feature maps depends on the input image and the learned VGG19 filters.

## Limitations

This experiment visualizes feature maps from only one image and a small number of convolutional layers.

The visual appearance of a feature map does not by itself provide a complete measure of model performance.

A more extensive analysis could evaluate multiple images and investigate feature maps across many layers.
